# Data-Transmission
## 概述

**私家传送站** 是一款为解决跨设备（如手机、电脑）间数据同步与传输问题而设计的轻量级工具。它特别适用于远程桌面场景下传统同步方式不便的情况，通过简单的本地服务实现快速、直接的文件与数据交换。

## 核心功能与目的

### 主要目的
- **解决跨设备数据同步难题**：在手机、电脑等不同设备间，尤其是通过远程桌面连接时，传统云盘或数据线传输方式往往不够便捷。本工具旨在搭建一个临时的、设备间的直连通道。
- **简化传输流程**：无需复杂配置，追求“开箱即用”的体验。

### 核心作用
1.  **文件传输**：在设备间互传任意文件。
2.  **输入数据传输**：例如，在手机上复制的文字、图片，可直接同步到电脑端粘贴。
3.  **跨设备传输**：作为上述功能的基础，建立设备间的通信桥梁。

## ⚠️ 重要安全提示

**请注意**：此工具目前**未经过严格的安全验证与加密**。其设计初衷是用于**可信的私有网络环境**（如家庭或公司内网）。

- **风险提示**：如果在公共网络或非受信网络中使用，可能存在数据被窃取的风险。
- **责任声明**：因在非私有网络使用而导致的数据泄露等安全问题，需由用户自行承担后果。
- **使用建议**：请务必在确认网络安全的前提下谨慎使用。

## 快速使用指南

### 1. 启动服务
操作极其简单，无需安装。只需在作为服务端的设备上（通常是电脑）执行 `main.exe` 程序。执行后，工具会自动在本地启动一个Web服务。

### 2. 访问控制界面
启动成功后，直接在浏览器中打开工具提供的本地网址（通常是 `http://localhost:端口号` 或 `http://本机IP:端口号`），即可看到简洁的网页控制界面。

### 3. 文件上传
- **点击选择文件**：在界面中找到“选择文件”按钮。
- **上传文件**：选中文件后，点击“上传至电脑”按钮。
- **查看进度**：上传开始后，界面会显示清晰的上传进度条。

- **文件列表**：上传完成后，文件会出现在下方的列表中，方便查看和管理。

### 5. 同步剪贴板与获取数据
- **图片/文字同步**：在手机或另一台设备上复制图片或文本后，在网页点击“同步到电脑”，即可将剪贴板内容发送至服务端电脑。
- **获取远程数据**：点击“从电脑获取”按钮，可以获取服务端电脑上已由其他方式（如“同步到电脑”操作）准备好的数据。

如果上传了文件但在列表中未立即显示，可以点击“刷新”按钮手动刷新列表，以获取最新的文件状态。
